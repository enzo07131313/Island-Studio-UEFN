# Island-Studio-UEFN
Projet de développement d'outils d'intelligence artificielle pour automatiser et faciliter la création de jeux Fortnite avec UEFN.

## Présentation du projet

Island Studio est un projet de développement d'outils permettant de faciliter la création d'expériences interactives dans Unreal Editor for Fortnite (UEFN).

## Fonctionnalités envisagées

- Assistance au développement par intelligence artificielle
- Automatisation de tâches dans UEFN
- Création et gestion de cartes Fortnite
- Amélioration des processus de développement et de test
- Intégration d'outils pour simplifier le travail des créateurs

## Avancement

Le projet est actuellement en phase de développement et d'expérimentation.

## Objectifs

Développer progressivement des outils fiables et accessibles pour améliorer la productivité des créateurs UEFN.
